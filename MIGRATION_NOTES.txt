- revenue/value = EasyOrders subtotal for uploaded order value.
- COD = KHOD/EasyOrders amountDue when known.
- commission/profit = KHOD marketerCommission when known.

- Analytics status breakdown counts only rows with khodStatusKnown/orderStatusKnown = true.
- "Missed" must not appear as a lifecycle status bucket.
- If no KHOD-known statuses exist yet, status widgets should show an empty/neutral state instead of fake placeholder statuses.
- Operations Product Performance uses only KHOD-known/enriched rows, so first-run EasyOrders-only uploads do not immediately count as KHOD product performance.
- Normal Analytics/Operations order tables may still show first-run rows, but should distinguish EasyOrders created time, source real/missed, and pending/unknown KHOD status until enrichment.

Results semantics:
- "Already in KHOD" means orders skipped because phone+SKU already exists in the KHOD export.
- Use realInKhod + missedInKhod, with compatibility fallback for old realInTaager/missedInTaager stats.
